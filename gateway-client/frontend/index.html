🌐 沉浸式翻译等浏览器插件
API URL：http://127.0.0.1:18123/v1/chat/completions
Key：local
💻 curl 命令行 
curl http://127.0.0.1:18123/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer local" \
  -d '{"model":"auto","messages":[{"role":"user","content":"你好"}]}'
🐍 Python OpenAI SDK 
from openai import OpenAI
client = OpenAI(base_url="http://127.0.0.1:18123/v1", api_key="local")
resp = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "你好"}])
print(resp.choices[0].message.content)

AI 模型网关

Version 2.0 · 本地运行 · 数据不出你的电脑

将多个免费/付费的 LLM API 源统一到一个 OpenAI 兼容接口背后，自动挑选最合适的模型回答你的问题。
✨ 功能特色
🎯 智能路由 根据问题难度自动匹配模型——简单问题走快模型省时间，复杂问题走强模型保质量
📊 实时监控 Token 用量一目了然，帮你算清省了多少钱
🔄 自动切换 某个源挂了或限流了，自动换下一个可用源，你无感知
🧩 自定义路由 把喜欢的模型组合成专属路由，一句话调用
🔒 本地优先 所有数据存在你自己电脑上，不经过第三方服务器
🛣️ 技术原理

每条请求按以下流程处理：

① 分类 — 规则速判（消息长度/代码/图片/上下文长度）
② 提示 — SIMPLE→速度优先；CODE→高能力优先
③ 多轴评分 — 能力 + 实测速度 + 可靠性 + 余量健康度
④ 松弛降级 — 条件太严时自动放宽重试
⑤ Fallback — 失败自动切换下一家供应商
