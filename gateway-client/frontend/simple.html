📖 怎么在其它软件里使用？（ChatBox / NextChat / 沉浸式翻译 等）
只需要填三项，任何支持「自定义 OpenAI 接口」的软件都能用：
① 接口地址(Base URL)：http://127.0.0.1:18123/v1
② API Key：随便填，比如 local
③ 模型名：填 auto 就行——系统会自动帮你挑最合适的模型；也可以在「模型广场」里挑具体名字

命令行调用示例：
curl http://127.0.0.1:18123/v1/chat/completions -H "Content-Type: application/json" -d "{\"model\":\"auto\",\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}]}"
