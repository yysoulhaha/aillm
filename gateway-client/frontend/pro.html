🚀 快速开始

桌面客户端双击 ai-gateway-c-client.exe 自动启动网关(:18123)；或命令行 py -3 server.py 后访问 http://127.0.0.1:18123/pro。普通版入口 /simple。

🔌 客户端接入

API Base : http://127.0.0.1:18123/v1　API Key : 任意值
模型名 : auto（全库自动挑）/ auto:free / 具体模型ID；可加 pool 参数限定免费或付费池

➕ 添加上游流程

① 新增供应商 → 填 ID/BaseURL(/v1 结尾)/协议/配额　② 填 Keys（免Key填 __KEYLESS__）
③ 🔍测试连通拉模型 → ⬇填入 → 保存　④ 「⇅同步」拉上游全量：原有保持，新增默认停用

🧠 智能路由

规则速判：≤15字→SIMPLE(快) | 含```/代码词→CODE(强) | 图片→VISION | ≥8000tok→LONG_CTX
无法判定→LLM 分类器；hint 未命中自动松弛降级（bench界→vision→minCtx→无）

📚 模型参数资料

从 DataLearner 抓参数量/上下文/发布时间用于展示与评分兜底；「免费/付费」标记后缀自动剥离后查询；负缓存可在「补全」时清除重试。

❓ 常见问题

端口占用：Get-NetTCPConnection -LocalPort 18123 → Stop-Process。
502：看监控日志最后错误，多为上游 Key 失效；熔断+Fallback 自动换家。
数据位置：配置 data\config.json；日志 logs\gateway.log；参数缓存 data\model_params.json
