AI智能网关

Version 2.0 · 本地优先 · 数据不出你的电脑

AI智能网关是一个本地部署的 LLM API 聚合代理，将多个免费/付费大语言模型 API 统一为 OpenAI 兼容接口，通过智能路由和多维度动态评分实现最优模型调度。
⚡ 核心架构
多轴动态评分 — 基于 EWMA（指数加权移动平均）算法，综合能力分 35%、实测速度 25%、可靠性 25%、余量健康度 15% 四个维度实时计算模型得分
智能路由引擎 — 规则速判 + 分类器双通道，根据消息内容自动匹配最优模型类别（简单→速度优先 / 代码→能力优先 / 视觉→多模态）
熔断降级机制 — 连续失败触发熔断（阈值 3 次），自动切换供应商；失败惩罚按时间衰减（每 5 分钟 -1，上限 15），确保系统韧性
松弛梯度重试 — 当首选模型不可用时，按优先级逐步放宽约束：优先级基准→最高能力→最新→最便宜→最远
🔧 技术特性
三协议互转 — 原生支持 OpenAI / Anthropic / Gemini 格式，自动协议转换，客户端无需适配
全链路日志 — 请求/响应全链路追踪，便于调试和监控
Token 压缩 — 长对话自动精简，降低 API 成本
🛡️ 安全设计
本地优先 — 所有数据存储在本地，API 密钥不经过第三方服务器
密钥隔离 — 支持多 Key 轮询，自动绕过单 Key 限流
